# A股量化个人研究台 V1.5

个人研究用途；**非证券投资建议，不连接券商账户，不执行真实交易**。

## 当前内容
- 手机 PWA：每日筛选、个股分析、自选股、模拟持仓、单股模拟回测。
- V1.4：个股分析、模拟持仓、历史回测支持输入6位代码或股票名称，并提供代码/名称联想选择。
- 每日选股增加可调价格区间，默认3–100元；优先按24小时内可用行情快照价过滤，无可用快照时按最近完整收盘价过滤。价格设置保存在本机。
- 盘中买入预警：收盘买入观察条件通过后，再检查盘中快照价格区间、MA5/MA10和按交易时段归一化的成交量；开盘前30分钟不发出量能确认预警。模拟持仓同步显示盘中止损、止盈、趋势转弱和T+1限制预警；缺少买入日期时暂停卖出预警。
- V1.5 信号追踪：每次收盘任务回溯当前已覆盖股票最近180个交易日的买入观察信号；次日开盘不追高入场，按A股T+1规则统计买入后第1/2/3个可卖交易日结果。展示完成样本、胜率、平均收益、平均盈利/亏损、事件序列回撤及最大连续亏损。
- 信号追踪是事件研究，不是组合级回测；当前历史成分覆盖不完整，可能存在幸存者偏差，指标不可直接解释为实盘组合收益。
- 行情使用腾讯财经非官方公开快照；GitHub Actions 每5分钟尝试采集，前端每5分钟拉取快照。实际可能因GitHub调度、队列、接口延迟或限流而更慢；只有单股源时间在15分钟内且处于A股交易时段才显示盘中预警，不是交易所逐笔实时行情。
- 自选股和模拟持仓仅使用当前设备浏览器 `localStorage`，不上传仓库，清理浏览器数据会丢失，请自行备份。
- V1.3 短线信号：收盘后筛选次日买入观察（MA5/MA10趋势、5日均量1.2倍、RSI14 45–68、接近前20日高点、ATR波动率<=6%）；信号仅下一交易日有效。
- 本机模拟持仓显示卖出观察：成本价±ATR止盈止损、MA5/MA10趋势转弱、买入日之后第3个交易日时间退出；录入买入日期后检查A股T+1限制。
- V1.3回测按同一套买卖规则模拟，固定100股、次日开盘在观察区间内才入场，含佣金、印花税和滑点假设。
- `data/screen.json` 是盘后研究结果；前端价格过滤基于全部已覆盖历史数据行，不是全市场完整覆盖。盘中买卖预警独立读取 quote-feed 快照。
- `quote-feed` 分支提供最近一次盘中行情快照；界面分别展示行情源时间与采集时间，过期判断以行情源时间为准，不把刚采集的旧报价误认为实时。
- 页面会明确显示行情日期和数据过期提醒，无真实数据时显示「未初始化」，**不会伪造任何实时价格或选股结果**。

## 启用 GitHub Pages
1. 打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
2. 打开 **Actions → AShare source tests and GitHub Pages → Run workflow**，并确认所有检查成功。
   - 也可以通过 `main` 分支的新提交触发部署；GitHub Pages 刚启用后，之前失败的工作流**不会自动变为成功**。
3. 网址：`https://gritechomepm-art.github.io/ashare-quant-personal/`，成功发布后才能访问。
4. **Actions → AShare daily EOD screening → Run workflow**：北京时间交易日收盘15:15以后才能运行。首次分批收集历史K线，每次最多300只；覆盖不足会明确标注。
5. **AShare best-effort intraday snapshots** 仅在A股工作日交易时段自动尝试更新，计划约5分钟一次，但 GitHub 调度和免费行情源可能延迟、被限流或失败。

## GitHub 工作流
- `.github/workflows/site.yml`：源码测试和静态网站部署。
- `.github/workflows/daily.yml`：交易日北京时间16:35盘后更新并重部署。
- `.github/workflows/quotes.yml`：交易时段每5分钟尝试通过独立 `quote-feed` 分支更新公开行情，不每次上传 Pages Artifact；GitHub schedule 不是实时调度器，不能保证准点。

## 已知限制
- 不保证行情为逐笔实时数据；腾讯公开快照可能延迟、缺失或限流，15分钟以外的盘中报价不生成预警。
- 历史数据覆盖仍是分批扩展；信号追踪只统计当前成功下载历史日线的股票，未覆盖股票不代表没有信号。
- 买卖信号是可解释的研究观察信号，不是自动委托或投资建议；策略参数尚需用完整历史样本做样本外验证。
- 策略历史回测未完整模拟停牌、涨跌停、历史退市股、分红除权及组合级资金占用；不可用于直接自动交易。
- 页面公开访问，持仓仅本机存储；建议定期导出本机记录，且不要把私有备份提交到仓库。
